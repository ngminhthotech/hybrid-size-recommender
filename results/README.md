# Results

Everything here is regenerated by `bash scripts/run_all.sh` (or `scripts\run_all.bat`).

| Path | Content |
| --- | --- |
| `experiment/<dataset>/summary.csv` | AUC, Macro-F1, accuracy (mean ± std over 10 seeds) by protocol, history bucket and model |
| `experiment/<dataset>/metrics_per_seed.csv` | Every metric for every seed (used for the boxplots) |
| `experiment/<dataset>/significance.csv` | ΔAUC of the proposed model vs. each model: 95% CI, bootstrap and t-test p-values |
| `experiment/<dataset>/size_rec_*.csv` | Size-recommendation accuracy (exact, within one size) |
| `experiment/<dataset>/config.json` | Seeds, models, hyper-parameters, dataset statistics |
| `figures/en/*.png` | Figures with English labels (used in the paper); `figures/*.png` are the Vietnamese versions |
| `figures/**/data/*.csv` | The numbers behind each figure |
| `models/*.pt` | Proposed model trained on all data, used by `sizerec recommend` |
| `logs/*.txt` | Console output of every step |
| `results_summary.xlsx` | All tables in one spreadsheet |
